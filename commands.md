# Here are ten Linux commands  
  
**vim** - Starts a great text editor  
**man** - Displays documentation for commands, administration and development  
**ssh** - Securely connect and execute commands on a remote system  
**scp** - Securely copy files to a remote system  
**curl** - Download web files using the CLI  
**systemctl** - Manage the Systemd monster init including the kitchen sink  
**sudo** - Run commands as root or another user  
**echo** - Send text to stdout or a file or pipe  
**ping** - test network connection by contacting another host  
**dd** - write disk images directly to USB keys and much more  
  
# Vim specific commands  
**:q!** - Escape the unescapable  
**dd** - Delete the current line  
**p** - Paste from unnamed register  
**ctrl-v** - Select text visually  
**/** - Search file  
**.** - Repeat last change
